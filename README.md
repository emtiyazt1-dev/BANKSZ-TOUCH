# SmartBank Android APK Project

This is an Android Studio project wrapping the SmartBank mobile-first banking UI in a native Android WebView.

## Build APK
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Select Build > Build APK(s).
4. The debug APK will be under app/build/outputs/apk/debug/.

This is a frontend/demo app. It does NOT connect to a real bank, payment network, KYC provider, card network, or real-money wallet. Production banking requires a secure backend, authentication/OTP, KYC/AML, encryption, audit logging, fraud controls, and licensed financial/payment integrations.
